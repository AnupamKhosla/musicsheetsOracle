# musicsheetsOracle

**Live site**: [musicsheets.site](https://musicsheets.site)
**Backup**: [musicsheets.tail0c6a25.ts.net](https://musicsheets.tail0c6a25.ts.net)

Convert Western MusicXML sheet music to Hindustani Bhatkhande notation with
side-by-side Western staff and Indian swara grid views.
